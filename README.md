# Evapotranspiration Models

A curated repository of **evapotranspiration (ET) model components** implemented across multiple **crop simulation platforms**, with standardized **Crop2ML** representations to support interoperability, comparison, and reuse.

---

## 🎯 Objectives

This repository aims to:

- Collect evapotranspiration components developed in different crop modeling platforms
- Preserve the **original source code** of each component for traceability
- Provide **Crop2ML-compliant components** for each ET model
- Facilitate model comparison, transpilation, and integration into multi-model workflows

---

## 📁 Repository Structure

The repository is organized **by crop simulation platform**.

### 🔹 Platform directories

Each top-level directory corresponds to a **crop simulation platform**
(e.g. STICS, DSSAT, APSIM, Simplace, etc.).

### 🔹 `Original/`

- Contains the **original evapotranspiration model implementations**
- Code is kept as close as possible to the platform source
- Purpose: transparency, reference, and scientific traceability

## 🚧 Status

This repository is under active development.  
New platforms and evapotranspiration components will be added progressively.
